# Sistema de analisis de tecnica RCP - OpenCV + MediaPipe + ArUco + Tkinter

## 1. Requisitos
- Python 3.13 
- Camara web USB 640x480 o superior, sin GPU requerida (RNF-06)

## 2. Entorno
```
venv\Scripts\activate.bat
pip install -r requirements.txt
```

## 3. Ejecutar la aplicacion
Doble clic en `ejecutar_rcp.bat`, o manualmente:
```
set TCL_LIBRARY=C:\Users\lucas\AppData\Local\Programs\Python\Python313\tcl\tcl8.6
set TK_LIBRARY=C:\Users\lucas\AppData\Local\Programs\Python\Python313\tcl\tk8.6
.\venv\Scripts\python main.py
```

## 4. Ejecutar las pruebas de criterios de aceptacion
```
.\venv\Scripts\python -m pruebas.test_criterios
```

## 5. Marcador ArUco
1. En la app: boton "Generar marcador ArUco" -> `aruco_ID0.png`.
2. Imprimir a 5.0 cm reales, sin "ajustar a pagina", en papel blanco mate.
3. Pegarlo plano en el pecho del mannequin o de la persona.

## 6. Uso
1. Colocar el marcador en el pecho y situarse frente a la camara (hombros, caderas y manos visibles).
2. "1. Iniciar sesion": la camara se activa en menos de 3 s.
3. Comprimir a 100-120 cpm y 5-6 cm de profundidad.
4. "2. Finalizar sesion": detiene camara y analisis y muestra el resumen.
